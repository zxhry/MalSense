How does the AI explain itself?
MalSense uses Explainable AI (SHAP). For every scan it measures how much each feature pushed the answer towards "malware" or towards "safe". Malware usually asks for many risky permissions (reading SMS, phone details, accounts), so asking for them is a sign of danger. Not asking for them is a sign of safety. Things like file size or number of screens only matter in combination with everything else.

What is VirusTotal?
VirusTotal is a free service that checks files with dozens of antivirus products at once. MalSense only sends the file's fingerprint (hash), never the file itself. If VirusTotal has never seen the file, it has no result – this is common for new or private apps.

{# Glossary #}

Words on this page
Malware
An app made to harm you, e.g. steal data or money, or spy on you.
Permission
Something an app must ask Android for, e.g. reading your contacts or SMS.
Malware probability
How likely the AI thinks the app is malware. 50% or more = malicious.
Antivirus engine
One antivirus company's scanner (e.g. Kaspersky, ESET) on VirusTotal.
SHA-256 hash
A unique fingerprint of the file. Any change to the file changes the hash.
False alarm
A safe app wrongly flagged as malware (false positive).
